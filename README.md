# 🎉 **Care Console** - University Hostel Healthcare Management System

**Care Console** is a comprehensive university hostel healthcare system built with the MERN stack and styled with **Tailwind CSS**, offering students seamless access to healthcare resources. This all-in-one platform enhances health accessibility and includes special features for users with impairments.

🚑 **Ambulance Tracking** • 🧑‍⚕️ **Patient Information Sharing** • 📲 **Mobile Access** • 🛍️ **Pharmacy Delivery** • 📈 **Real-Time Health Monitoring**

## 🛠 **Technologies Used**
- **Frontend**: React (Care Console and Health Care components)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Mobile**: React Native (Android) - **CareMate** app
- **Styling**: Tailwind CSS

---

## 📚 **Libraries and APIs**
- **Chart.js**: Interactive data visualization on the dashboard
- **Tesseract OCR**: Optical Character Recognition for patient records
- **Gemini AI API**: Patient care analytics
- **Twilio API**: Automated call/SMS for healthcare notifications
- **Jitsi**: Video consultations between doctors and patients

---

## 💡 **Problem Statement**
Develop a university hostel healthcare system with essential features:

- 🚑 **Ambulance Tracking**
- 🧑‍⚕️ **Patient Information Sharing**
- ⚠️ **Isolation Alerts** (for contagious illnesses)
- 💊 **Pharmacy Delivery**
- 🌐 **Accessibility for Impairments** (multi-language and accessible UI)
- ⏱️ **Real-Time Device Monitoring**
